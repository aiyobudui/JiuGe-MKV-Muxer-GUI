# 2026-07-30

## BUG 修复：多字幕轨道读不到（视频轨/音轨同样有连带显示问题）
- 现象：添加含多配音+多字幕的 MKV 后，「字幕轨」列显示 0、轨道选择对话框里字幕为空，混流时字幕被丢弃。
- 根因（`packages/Tabs/VideoTab/VideoSelection.py` 的 `_get_track_info_worker`）：
  1. 【致命】匹配字幕时写成了 `track_type == 'subtitle'`（单数），而 mkvmerge `-J` 输出的字幕轨道 type 是 `"subtitles"`（复数）→ 字幕列表永远为空。对比 `TrackInfo.get_subtitle_tracks` 用的是正确复数形式，正好印证。
  2. 【连带显示错】worker 把原始 mkvmerge track 字典（language/name/is_default 都在 `properties` 里）直接存入 `VIDEO_OLD_TRACKS_*_INFO`；但下游 `TrackSelectionDialog` / `build_mkvmerge_args` 按顶层键 `track.get('language')` 等取值 → 语言恒为 und、名称恒空、默认轨恒未勾（音轨/视频轨同样受影响，只是「轨数」列因为用 len() 能数对而没暴露）。
- 修复：重写 `_get_track_info_worker`，仅调用一次 `get_video_tracks_info`（不重复起 5 次子进程），再映射成与 `TrackInfo.get_*_tracks` 一致的「加工字典」（顶层 id/language/name/is_default/is_forced/codec，音轨另有 channels/sample_rate，视频另有 width/height）。既修正字幕 type，又修复所有轨道的语言/名称/默认轨显示。附件保持原始字典（其字段本就是顶层）。
- 验证：py_compile 通过；用模拟 mkvmerge -J 输出独立测试，多音轨(2)+多字幕(3)+视频(1)+附件(1) 全部正确归类、字段正确。GUI 依赖 PySide6 本沙箱未装，需本机实测（加多字幕文件→字幕轨列应显示正确数量、对话框能列出并可设语言/默认）。
